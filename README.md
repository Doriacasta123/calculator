# 🎉 Calculator for Kids 🧮

## ✨ What's This All About?

Welcome to **Calculator for Kids**, a gentle, inclusive desktop app thoughtfully designed for **children on the autism spectrum**. This interactive calculator offers a **visually soft interface**, **voice feedback**, and **celebratory confetti** to encourage engagement and learning through positive reinforcement.

Whether it’s learning to use a calculator or solving basic addition problems, this tool creates a playful and safe space for math exploration.

---

## 🔎 Features

- 🌈 **Soothing Visual Mode** — Soft pastel colors, rounded buttons, and clean layout for reduced sensory overload.
- 🗣️ **Text-to-Speech Feedback** — Every number and result is spoken aloud to enhance auditory processing.
- 🎊 **Confetti Animation** — Visual reward system to celebrate every achievement.
- 🧠 **Challenge Mode** — Friendly math problems with instant feedback and positive reinforcement.

---

## 🛠️ Tech Stack

- **Python** – Core language  
- **Tkinter** – For the graphical interface  
- **pyttsx3** – For speech output  
- **Random** – To generate challenges and confetti positions  

---

## 🚧 Project Status

This project is a working prototype aimed at children with diverse cognitive profiles. Future improvements may include:

- ➗ More operations (subtraction, division…)
- 🧩 Custom challenges by difficulty level
- 📊 Progress tracking and rewards system
